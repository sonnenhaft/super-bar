# Super Bar 1.2.25

A single macOS menu bar app for TCL Home and LG ThinQ air conditioners and BLUETTI power stations.

- Unified device cards, brand tabs, refresh settings, text sizing, and launch-at-login controls.
- Immediate device selection, expandable active cards, and drag-to-reorder device names.
- Room temperature for powered-off air conditioners; refresh controls only on the active card.
- Custom temperature and airflow pickers, with one fan-mode selector below airflow controls.
- Matching seven-day energy and 24-hour power charts with hover values and a seven-day total.
- Smaller corner radii, thin borders, consistent spacing, and a translucent blue menu background.
- English documentation and installer output, with a screenshot in the README.

The attached ZIP contains an optimized, ad-hoc signed Apple Silicon build for macOS 15 or later. Extract **Super Bar.app** and move it to **Applications**. Intel Macs can build from source using Apple Command Line Tools.

Device credentials and local readings are not included. Configure LG through **LG settings…**, sign in to TCL Home if prompted, and grant Bluetooth access when opening BLUETTI.
